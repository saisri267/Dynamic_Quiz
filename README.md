
# Dynamic Quiz Application – Selenium Automation

## About
This project is a **dynamic quiz application** with category & difficulty selection, per-question timer, result analysis, and quiz restart functionality.  
End-to-end **automation testing** is implemented using **Selenium WebDriver (Python)** to validate UI behavior, warnings, navigation, and results.

---

## How to Download & Run

### 1. Download
- Clone or download this project
- Place it inside:
```

C:\xampp\htdocs\QUIZ_APP

```

### 2. Run Application
- Start **Apache** from XAMPP
- Open browser:
```

[http://localhost/QUIZ_APP](http://localhost/QUIZ_APP)

````

### 3. Run Automation Tests
```bash
cd C:\xampp\htdocs\QUIZ_APP\quiz_automation
pip install selenium webdriver-manager
python test_quiz.py
````

Screenshots will be saved in:

```
quiz_automation/screenshots/
```
